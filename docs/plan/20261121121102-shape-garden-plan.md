# 🌱 모양 정원 MVP 구현 계획

## 📖 개요

[리뷰](../review/20261121121102-shape-garden-review.md)를 입력으로 한다. 주 대상 만 3~5세, 목표는 색과 무관하게 같은 모양을 대응하는 것이다. 이번 작업은 조사부터 구현·검증까지 위임받았고 외부 배포·커밋은 포함하지 않는다.

### 📐 상태와 파일

상태: 시작 → 시범 또는 활동 → 정답 확인/힌트 → 다음 활동 → 완료. 활동 어디서든 쉬기 dialog와 목록 복귀 가능하다. 보호자 dialog는 안내 확인 후 선택지 수 2/3·소리·이 콘텐츠 저장 초기화를 제공한다. 새로고침 시 자동 활동 재개 대신 시작 화면에서 이어 하기를 제시한다.

파일: `apps/catalog.js`, `apps/index.html`, `apps/home.js`, `apps/site.css`, `apps/shape-garden/index.html`, `apps/shape-garden/style.css`, `apps/shape-garden/src/{activity,storage,render,main}.js`, 루트 `index.html`, `tools/verify-shape-garden.mjs`.

### 🖐 컴포넌트와 레이아웃

아이 선택은 실제 button 기반 큰 모양 타일, 완료는 진행 화단 그림, 설정은 실제 radio·checkbox를 label 카드/스위치로 스타일링한다. 팝업은 native dialog로 초점·취소를 지원한다. 기본 폼 외형을 노출하지 않되 의미와 접근 가능한 이름을 유지한다. 버튼은 최소 56px, 글·색 외에 모양을 제공한다. 시각적 모양 윤곽은 진한 잎색으로 고정해 채움색에 의존하지 않는다.

모바일은 위 목표·아래 선택, 태블릿/데스크톱은 넓은 정원과 중앙 선택 그룹, 목록은 화면 폭에 따라 카드 그리드를 재배치한다. 부모 설정은 긴 문구·작은 화면에서 세로 스크롤한다.

### 🛡 저장과 제한

키는 `shape-garden:v1:preferences`, `shape-garden:v1:progress` 두 개만 사용한다. preferences는 sound boolean·choices 2/3, progress는 uint32 시드와 `matched|skipped` 결과 최대 5개다. 사용자 식별·오답 이력·시간·생년월일은 저장하지 않는다. 잘못된 JSON과 범위는 기본값, 저장소가 막히면 메모리로 진행한다. 초기화는 두 키만 삭제한다.

실제 아이·iOS Safari·VoiceOver 검증은 가능 여부를 별도 표시한다. 브라우저 자동 검증 결과로 발달 효과나 실기기 적합성을 단정하지 않는다.
