# 🛠 로봇 첫걸음 구현 계획

## 📖 개요

만 6~8세를 주 대상으로 순서와 코딩의 가능성을 검토한다.

## 🧩 주요 내용

| 항목 | 계획 및 구현 범위 |
|---|---|
| 핵심 목표 | 앞으로와 회전 명령을 이어 작은 로봇에게 길을 알려줘요. |
| 고유 장면 | 바닥 지도와 명령 쪽지 책상 |
| 컬러·언어 | 연녹 바닥, 노란 로봇과 구분되는 장애물, 호기심과 재시도를 돕는 문구 |
| 세션 | 3회 활동, 시간 제한 없음. 풍부한 난이도 팩을 뜻하지 않음 |
| 규칙 검사 | 지도 경계·장애물, 명령 24개 제한·복구 |
| 구조 | model은 순수 상태 전이, view는 상태 표현, activity는 공통 어댑터 |
| 저장 | 기존 공통 slug:v1 진행 이력·시드 복원. 다른 앱 저장에 접근하지 않음 |
| 도움 | model.hint의 실제 사용 가능한 버튼을 표시 |
| 반응형 | 글자·터치 버튼을 유지하고 도구·지도·설명 패널을 세로로 재배치 |
| 접근성 | 실제 button, 한국어 이름, 선택 상태, 키보드·초점·글로 된 상태 안내 |

로컬 2D 지도와 전진·좌회전·우회전 명령만 구현한다. AI·3D·VR·AR·계정·외부 서버는 제외했다. 경로 힌트는 위치와 방향을 함께 탐색하는 BFS다.

독립 `style.css`를 data-app 아래로 제한한다. 자체 `cover.svg`는 목록·시작·완료에도 연결한다. 공통 UI와 저장 API를 바꾸지 않고 콘텐츠 장면을 교체할 수 있도록 한다. 기존 31개 규칙도 전체 회귀 검사한다.
