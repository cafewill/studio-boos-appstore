# 🛠 그림 낱말 지도 계획

## 📖 개요

새로운 조작과 발견 결과를 가진 작은 콘텐츠로 구현한다.

## 🧩 주요 내용

| 항목 | 설계 및 구현 |
|---|---|
| 학습·탐색 목표 | 장면의 사물과 한국어·영어 낱말을 함께 살펴봐요. |
| 대상 | 만 6~8세, 내부 설계 기준 |
| 고유 장면 | 나무·배·집의 한국어/영어 지도 |
| 작은 발견 | 그림과 낱말에 따라 행동 직후 상태·장면이 달라짐 |
| 핵심 규칙 | 선택한 낱말만 공개·중복 수집 금지 |
| 한 세션 | 3회. 1회 창작은 정답을 강요하지 않음 |
| 조작 | 실제 button·선택 상태·도움·되돌리기, 드래그 필수 아님 |
| 모바일 | 도구 재배치·버튼 60px, 공간판은 유동 폭. 화면 축소로 글자만 줄이지 않음 |
| 태블릿·데스크톱 | 장면의 최대 폭 유지, 봉투·작업대·책상은 필요한 곳에서 나란히 배치 |
| 저장 | slug:v1 시드·활동 번호·조작 이력. 다른 콘텐츠 키 접근 없음 |
| 움직임·소리 | 자동 점멸·시간 압박 없음. 상태 중심 그림, 소리는 선택 사항 |

기본 낱말과 자체 그림만 사용한다. 원작 사전 데이터·뜻풀이·사진·발음 파일은 가져오지 않는다.

model은 DOM 없는 순수 상태 전이·힌트, view는 표현, activity는 공통 수명주기 어댑터다. 반복 사용하는 BFS와 표현 도구만 shared로 분리한다. 다른 콘텐츠 모델을 import하지 않는다. 콘텐츠별 CSS와 SVG를 유지한다.

컬러는 기존 짙은 잎색 글자·경계와 살구·민트·보라·노랑을 재료별로 사용한다. 색 외에 텍스트·무늬·형태를 함께 제공한다. 색으로 감정·능력·성별을 판정하지 않는다. 교육 효과·정서 효과를 보장하지 않는다.
