# ✅ 콘텐츠 검증 가이드

## 📖 개요

기능뿐 아니라 아이가 이해하고 종료할 수 있는지, 문제와 피드백이 정확한지 검증한다. 문서 확인·자동 검증·브라우저 관찰·실기기·아이 관찰을 서로 대체했다고 보고하지 않는다.

브라우저 반응형 모드는 iOS Safari 실기기 검증으로 표기하지 않는다. 소리 없는 저연령 콘텐츠의 이해 가능성은 그림·시범 검토로 우선 평가하고 실제 아이 관찰 여부를 별도로 남긴다.

### 🧪 검증 방법

- 구현된 JS는 `node --check apps/{slug}/src/main.js`처럼 파일별 문법을 확인한다. ES Modules 인식은 실행 환경을 확인한다.
- 정답 판정·문제 생성·저장 복구처럼 오류가 의미 있는 규칙에는 작고 독립적인 자동 검증을 작성한다. 단순 문구·색 변경에 구현을 복제하는 테스트는 만들지 않는다.
- 저장소 예외는 localStorage 래퍼에 실패를 주입하거나 차단 환경으로 확인한다. 시크릿 모드만으로 저장 실패를 재현했다고 단정하지 않는다.
- 브라우저에서는 핵심 루프·접근성·네트워크·저장·회전을 실제 조작한다. 실행할 수 없는 항목은 사유와 남은 확인을 적는다.
