# 🔍 콘텐츠 조사·리뷰 가이드

## 📖 개요

앱의 인기보다 아이의 행동·이해·학습 과정을 먼저 분석한다. 실제 원작을 조사하는 작업에서는 최신 App Store 페이지와 개발사 자료를 확인한다. 이번 문서는 절차이며 특정 앱 추천이나 최신 차트 결과가 아니다.

## 🧩 주요 내용

### 🔄 조사와 선정

1. 기본 스토어는 대한민국 `apps.apple.com/kr/`로 한다. 게임·교육·어린이 관련 노출 영역과 개발사 공식 자료에서 후보 3~5개를 조사한다.
2. 앱명·개발사·직접 URL·조회일·버전·가격·앱 내 구입·광고·스토어 연령 등급·확인된 카테고리를 기록한다. 순위를 쓰면 지역·차트명·조회 시각도 적는다. 보이지 않는 항목은 미확인으로 둔다.
3. 원작 체험, 공식 소개, 영상 관찰, 추정을 분리한다. 스크린샷만 보고 문제 생성 규칙이나 전체 학습 효과를 단정하지 않는다.
4. 대상 연령·핵심 경험·웹 재현 가능성·자체 문제 제작 가능성을 비교하고 한 콘텐츠의 MVP를 정한다.
5. 계정·서버·라이선스 캐릭터가 핵심인 후보는 우선순위를 낮춘다. 원작의 결제·보상·광고 구조는 분석하되 재현 범위에서 제외한다.
