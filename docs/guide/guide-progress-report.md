# 🕒 장시간 작업 중간 보고

## 📖 개요

사용자 요청에 따라 5분 이상 이어지는 작업에서 매 5분마다 진행 상황을 알린다. 향후 이 저장소의 조사·설계·구현·검증·Git 작업에 계속 적용한다.

## 🧩 주요 내용

- 작업 시작 시각과 마지막 중간 보고 시각을 기준으로 보고 주기를 관리한다. 5분을 넘길 것으로 예상되면 첫 5분이 지나기 전에 현재 상황을 알리고, 이후 보고 간격도 5분을 넘기지 않는다.
- 중요한 발견·실패·방향 변경은 주기를 기다리지 않고 바로 알린다. 더 잦은 진행 보고도 허용한다.
- 보고 내용은 완료한 일, 현재 진행 중인 일, 다음 단계, 장애·미검증 사항을 짧게 정리한다. 예상 시간은 근거가 있을 때만 제시한다.
- 긴 도구 작업은 진행 중인 세션으로 실행하고 적절히 결과를 확인한다. 한 번의 장시간 대기 때문에 보고가 끊기지 않게 한다.
- 사용자 추가 요청은 기존 작업에 반영하고 독립적으로 진행 가능한 일은 계속한다. 중간 보고를 반복 승인 요청이나 작업 종료로 바꾸지 않는다.
- 컨텍스트 압축·자동 연속 진행 뒤에도 기존 완료 내용·남은 범위·보고 주기를 이어간다. 같은 완료 내용을 새 작업처럼 반복하지 않는다.
- 최종 보고에는 구현·검증·미검증·Git 상태를 실제 근거와 함께 구분한다. 중간 보고를 읽지 않아도 이해할 수 있게 작성한다.

보고 예: “30개 중 20개의 핵심 규칙을 구현했습니다. 나머지 공간·창작 활동을 구현 중이며, 이후 전체 회귀 검사를 진행합니다. 브라우저 검증은 아직 미실시입니다.”
