# 🔢 목록 상단 개수 검증

## 📖 개요

첫 화면 상단에서 전체와 카테고리별 플레이 가능한 놀이 개수를 확인하고 해당 분야로 이동한다.

## 🧩 주요 내용

- 집계: implemented·verified만 포함. 현재 전체 71개, 배우기 29개, 생각놀이 26개, 표현놀이 16개다. 숫자는 UI에 고정하지 않고 catalog에서 계산한다.
- 선택: 상단 카드는 분야 선택·연령 전체·검색 초기화·목록 이동과 제목 초점을 제공한다. 하단 분야/연령 필터와 상단 선택 상태를 동기화한다.
- 표시: 상단은 검색 전 전체 수를 유지하고 결과 안내는 ‘전체 N개 중 M개’로 구분한다. 빈 검색 결과에서도 전체 수는 유지한다.
- 반응형: 넓은 화면 네 카드, 960px 이하 두 열, 340px 이하 장식 아이콘 생략. 필수 숫자·레이블은 유지하고 잘라내지 않는다. 모바일 하단 분야 필터도 두 열로 구성한다.
- 접근성: button·aria-pressed·분야/개수/행동을 포함한 이름·초점 표시. 색 외에 아이콘·텍스트를 제공한다. 숫자 애니메이션 없음.
- 자동 검사: `node tools/verify-catalog-summary.mjs` 통과. 실제 집계와 카테고리 합계, 미구현 후보 제외, 빈 목록·복합 필터·입력 불변성을 확인했다.
- 전체 회귀: `node tools/check-all.mjs` 결과는 [로그](20261121203131-catalog-counts-checks.log) 참조.
- 브라우저: 선택적 verify-browser에 폭별 카드 개수·카테고리 전환·검색 초기화·양방향 선택 동기화·넘침 검사를 추가했다. 이번 실행도 `Target page, context or browser has been closed`로 시작 직후 종료되어 화면·터치 검증은 미실시다. [실행 시도](20261121203131-catalog-counts-browser.json).
