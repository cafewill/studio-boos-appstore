# 🧸 studio-boos-appstore

## 📖 개요

App Store의 아이들용 게임·교육·창작 콘텐츠를 리뷰하고, 핵심 놀이와 학습 경험을 자체 이름·디자인·문제로 재구현하는 로컬 웹 프로토타입 프로젝트다. 여기서 클론은 상호작용과 규칙을 분석해 재구성하는 의미다.

## 🧩 주요 내용

- 대상: 만 3~5세, 6~8세, 9~12세. 콘텐츠별로 한 연령군을 먼저 정한다. 이 구분은 내부 설계 기준이며 App Store 등급과 다르다.
- 분야: 퍼즐·분류·수 세기·언어·관찰·논리·미술·음악·자유 놀이.
- 기본: HTML/CSS + Vanilla JavaScript ES Modules. 학습 UI는 DOM, 연속 움직임은 Canvas를 선택한다.
- 표현 원칙: 아이들의 정서 함양과 발달 적합성을 고려해 컬러 컨셉·용어·네이밍·피드백을 항상 검토한다.
- UI 원칙: “Fascinating”의 절제된 놀라움과 호기심을 간결하고 직관적인 커스텀 반응형 UI로 표현한다.
- 권리 원칙: 추상 규칙만 참고하고 표현·코드·문제는 독립 제작하며, 모든 단계에서 출처·라이선스·원작과의 혼동 가능성을 점검한다.
- 산출물: 앱 리뷰, 구현 계획, 독립 콘텐츠, 검증 기록.
- 현재 상태: 차트 396개 재검토·공식 소개 106개 추가 확인, 우선 후보 30개 구현 및 기존 모양 정원 공통 호스트 전환. 추가 분야 확장 10개를 포함해 총 71개 콘텐츠와 목록 필터 제공. 자동 규칙·구조 검사 통과, 실제 브라우저 플레이는 환경 제한으로 미실시.

```bash
python3 -m http.server 7902 --bind 127.0.0.1
```
