# 🌱 소리 탐험

## 📖 개요

짧은 소리와 그림 무늬의 짝을 찾아요. 주 대상은 만 3~5세이며 학습 능력 진단을 제공하지 않는다.

## 🧩 주요 내용

- 실행: 저장소 루트에서 `python3 -m http.server 7902 --bind 127.0.0.1`, 접속 `http://127.0.0.1:7902/apps/sound-discovery/`.
- 조작: 시작 후 화면의 안내대로 큰 버튼·타일을 탭한다. 모든 핵심 조작은 DOM button과 키보드 Tab/Enter/Space를 사용한다. 타일 이동은 선택 후 목적지 탭 방식이다.
- 활동: 소리·무늬 대응, 5개 활동을 차례로 진행하며 다음은 직접 누른다.
- 도움: 다음에 살펴볼 조작 후보의 테두리를 표시한다. 되돌리기·건너뛰기·쉬기는 불이익 없이 사용할 수 있다.
- 저장: `sound-discovery:v1:preferences`와 `sound-discovery:v1:progress`. 소리·시드·활동 번호·조작 이력만 저장한다. 읽기만 허용된 저장소에서는 새로고침 뒤 이전 값이 나타날 수 있다. 이력이 512개를 초과하면 현재 활동은 메모리로 계속하고 해당 진행의 영구 저장을 중지한다.
- 소리: 기본 꺼짐. 필요한 경우 공통 Web Audio의 자체 합성음만 사용하며, 실제 음성·악기 녹음을 재현한 것으로 표시하지 않는다.
- 소스: 규칙은 model.js, 화면은 view.js, 수명주기 어댑터는 activity.js, 진입은 main.js. 공통 호스트가 시작·설정·쉬기·완료·저장을 관리한다.

### 🛡 자체 제작과 권리 기록

추상 활동의 참고는 내부 [분석 문서](../../docs/review/20261121143203-sound-discovery-review.md)에만 적었다. 자체 화면·문구·SVG·규칙·문제/레벨 생성·합성음은 이 저장소에서 작성했다. 외부 이미지·음원·폰트·아이콘 파일이나 원작 코드·레벨을 사용하지 않았다. 자체 정원 색상·큰 타일·도움/쉼 흐름을 사용하며 원작의 캐릭터와 화면 배치를 복제하지 않는다. 원작 화면 대조·상표·특허·법률 검토는 미실시다.
