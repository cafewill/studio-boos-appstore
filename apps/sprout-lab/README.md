# 🧸 새싹 실험실

## 📖 개요

빛과 물을 번갈아 주며 씨앗의 변화를 살펴봐요.

## 🧩 주요 내용

- 주 대상: 만 3~5세. 조작은 화면의 이름 붙은 버튼을 선택한다. 드래그·소리는 필수가 아니다.
- 장면: 흙 단면 관찰 창, 뿌리·잎·꽃, 물/빛 도구. 색: 흙·연녹색과 복숭아 꽃.
- 도움: ‘한 걸음 도움’으로 다음 조작을 확인한다. 되돌리기·쉬기·보호자·목록은 공통 기능이다.
- 로컬 주소: `http://127.0.0.1:7902/apps/sprout-lab/`.
- 파일: `src/model.js` 규칙, `src/view.js` 장면, `style.css` 배치, `cover.svg` 자체 썸네일.
- 제한: 물·빛을 함께 주면 다음 성장 상태가 보이는 관찰 장난감이다. 광합성 계산·품종별 재배 조건·실제 시간은 재현하지 않는다. 물과 빛만 있으면 어떤 식물도 반드시 꽃을 피운다는 뜻이 아니다.
