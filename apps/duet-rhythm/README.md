# 🧸 함께 박자길

## 📖 개요

## 🧩 주요 내용

- 주 대상: 만 6~8세. 1회 활동. 놀이 속 읽기와 조작은 보호자와 함께 살펴봐도 좋다.
- 장면: 햇살/바람 친구의 차례가 교차하는 박자길. 실제 이름 붙은 버튼을 선택하며 드래그·소리는 필수가 아니다.
- 한 걸음 도움·되돌리기·쉬기·보호자·목록은 공통 위치와 의미를 유지한다.
- 주소: `http://127.0.0.1:7902/apps/duet-rhythm/`.
- 파일: `src/model.js` 규칙, `src/view.js` 표현, `style.css` 공간 구성, `cover.svg` 자체 아트.
- 핵심 확인: 8칸 기록·쉼 포함·소리 없어도 동일 창작.
- 한계: 한 기기에서 차례를 나누는 추상 경험을 협력 리듬 창작으로 전환했다. 원작 스포츠·경쟁·타이머는 제외한다.
