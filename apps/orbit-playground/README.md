# 🧸 행성 산책

## 📖 개요

태양 가까운 행성을 차례로 놓고 움직임을 관찰해요.

## 🧩 주요 내용

- 주 대상: 만 6~8세. 조작은 화면의 이름 붙은 버튼을 선택한다. 드래그·소리는 필수가 아니다.
- 장면: 궤도 무대, 행성 트레이, 놓을 자리와 시간 버튼. 색: 푸른 회색 우주와 네 행성 색.
- 도움: ‘한 걸음 도움’으로 다음 조작을 확인한다. 되돌리기·쉬기·보호자·목록은 공통 기능이다.
- 로컬 주소: `http://127.0.0.1:7902/apps/orbit-playground/`.
- 파일: `src/model.js` 규칙, `src/view.js` 장면, `style.css` 배치, `cover.svg` 자체 썸네일.
- 제한: 행성 순서는 [NASA 행성 소개](https://science.nasa.gov/solar-system/planets/)를 확인했다. 안쪽 네 행성만 포함한다. 크기·거리·공전 주기·현재 위치를 재현하지 않는다.
