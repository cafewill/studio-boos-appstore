# 🧸 움직이는 징검돌

## 📖 개요

돌의 차례를 기다리고 맞닿은 돌로 한 걸음씩 건너요.

## 🧩 주요 내용

- 주 대상: 만 6~8세. 3회 활동. 놀이 속 읽기와 조작은 보호자와 함께 살펴봐도 좋다.
- 장면: 수동 차례의 강물과 움직이는 징검돌. 실제 이름 붙은 버튼을 선택하며 드래그·소리는 필수가 아니다.
- 한 걸음 도움·되돌리기·쉬기·보호자·목록은 공통 위치와 의미를 유지한다.
- 주소: `http://127.0.0.1:7902/apps/crossing-stones/`.
- 파일: `src/model.js` 규칙, `src/view.js` 표현, `style.css` 공간 구성, `cover.svg` 자체 아트.
- 핵심 확인: 강물 경계·돌 위 유지·기다림 후 도달.
- 한계: 수동 차례와 자체 돌만 사용한다. 도로·차량·죽음·원작 8비트 캐릭터·반응 속도 경쟁은 제외한다.
