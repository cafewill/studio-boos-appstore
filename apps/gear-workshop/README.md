# 🧸 톱니 작업실

## 📖 개요

톱니를 연결하고 손잡이의 움직임이 전달되는 모습을 봐요.

## 🧩 주요 내용

- 주 대상: 만 6~8세. 조작은 화면의 이름 붙은 버튼을 선택한다. 드래그·소리는 필수가 아니다.
- 장면: 나무 작업판, 톱니 축, 손잡이와 회전 방향 표시. 색: 나무색·민트·보라·살구.
- 도움: ‘한 걸음 도움’으로 다음 조작을 확인한다. 되돌리기·쉬기·보호자·목록은 공통 기능이다.
- 로컬 주소: `http://127.0.0.1:7902/apps/gear-workshop/`.
- 파일: `src/model.js` 규칙, `src/view.js` 장면, `style.css` 배치, `cover.svg` 자체 썸네일.
- 제한: 같은 크기의 바깥 톱니를 선형으로 연결한다. 접촉한 이웃은 반대 방향, 끊긴 연결 뒤는 정지한다. 관성·마찰·복잡한 치형·하중을 생략했다.
