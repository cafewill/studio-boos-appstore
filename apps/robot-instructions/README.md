# 🧸 로봇 첫걸음

## 📖 개요

앞으로와 회전 명령을 이어 작은 로봇에게 길을 알려줘요.

## 🧩 주요 내용

- 로컬 주소: `http://127.0.0.1:7902/apps/robot-instructions/`.
- 파일: `src/model.js` 규칙, `src/view.js` 장면, `style.css` 배치, `cover.svg` 자체 썸네일.
