# 🧸 숫자 배 정박

## 📖 개요

새 숫자보다 작은 끝 숫자 중 가장 가까운 항구를 찾아요.

## 🧩 주요 내용

- 주 대상: 만 9~12세. 3회 활동. 놀이 속 읽기와 조작은 보호자와 함께 살펴봐도 좋다.
- 장면: 가까운 작은 수에 배를 놓는 숫자 항구. 실제 이름 붙은 버튼을 선택하며 드래그·소리는 필수가 아니다.
- 한 걸음 도움·되돌리기·쉬기·보호자·목록은 공통 위치와 의미를 유지한다.
- 주소: `http://127.0.0.1:7902/apps/number-harbor/`.
- 파일: `src/model.js` 규칙, `src/view.js` 표현, `style.css` 공간 구성, `cover.svg` 자체 아트.
- 핵심 확인: 증가 수열·한 차례 한 배·최근접 선행 수.
- 한계: 가장 가까운 작은 수 선택만 참고한다. 원작 카드·벌점·수용량·대전 규칙은 제외한다.
