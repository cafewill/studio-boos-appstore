# 🧸 물방울 연구소

## 📖 개요

밸브를 고르고 물을 한 칸씩 보내 세 화분을 돌봐요.

## 🧩 주요 내용

- 주 대상: 만 6~8세. 조작은 화면의 이름 붙은 버튼을 선택한다. 드래그·소리는 필수가 아니다.
- 장면: 물통·분기 배관·밸브·세 화분. 색: 물의 청록색과 화분의 흙색.
- 도움: ‘한 걸음 도움’으로 다음 조작을 확인한다. 되돌리기·쉬기·보호자·목록은 공통 기능이다.
- 로컬 주소: `http://127.0.0.1:7902/apps/water-workshop/`.
- 파일: `src/model.js` 규칙, `src/view.js` 장면, `style.css` 배치, `cover.svg` 자체 썸네일.
- 제한: 물 6단위의 보존과 컵별 목표 용량을 확인한다. 실제 유체 역학·압력·식물별 물 요구량을 재현하지 않는다.
