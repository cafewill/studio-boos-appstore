# 🌱 모양 정원

## 📖 개요

만 3~5세를 주 대상으로 한 자체 도형 대응 놀이. 색이 달라도 같은 모양을 구분하는 행동을 목표로 한다. 개발자 설계 목표이며 실제 아이 관찰·교육 효과 검증은 하지 않았다.

## 🧩 주요 내용

### 🚀 실행과 조작

저장소 루트에서 `python3 -m http.server 7902 --bind 127.0.0.1` 실행 후 `http://127.0.0.1:7902/apps/shape-garden/`에 접속한다. `file://` 실행은 지원하지 않는다.

1. ‘정원에 들어가기’를 누르거나 시작 후 목표 모양과 선택 버튼을 함께 살펴본다.
2. 화단의 모양과 같은 모양 버튼을 탭한다. 마우스·키보드 Tab/Enter/Space도 사용한다.
3. 다른 모양을 골라도 같은 활동에서 재시도한다. 두 번의 오답 또는 공통 ‘한 걸음 도움’으로 윤곽 힌트를 본다. 힌트 뒤에는 건너뛸 수 있다.
4. 맞히면 모양이 꽃 중심이 된다. ‘다음 발견’로 진행하며 다섯 활동 후 쉬기·새 정원을 고른다.
5. 상단 ‘쉬기’는 언제든 사용한다. 소리는 기본 꺼짐이다.

### 🧸 보호자와 저장

보호자 안내를 확인하면 선택지 수 2/3과 소리를 조절할 수 있다. 진행한 활동은 유지한다. ‘기록 지우기’는 별도 확인 후 이 콘텐츠 설정과 진행만 삭제한다. 이 진입 절차는 인증이나 법적 동의 수단이 아니다.

| 저장 키 | 값과 범위 |
|---|---|
| `shape-garden:v1:preferences` | sound boolean, choices 2 또는 3 |
| `shape-garden:v1:progress` | uint32 seed, matched/skipped 최대 5개 |

이름·생년월일·오답 이력·시간·기기 식별자·작품을 저장하지 않는다. 저장 실패 시 세션 메모리로 진행한다. 브라우저가 읽기는 허용하고 쓰기·삭제만 차단하면 현재 세션의 변경·초기화는 유지하지만 새로고침 뒤 기존 저장값이 다시 보일 수 있다. 새로고침은 시작 화면에서 완료한 라운드의 다음 활동을 이어 한다. 정답 후 ‘다음’을 누르기 전 상태는 저장하지 않는다. 완료한 정원은 시작 버튼으로 새 정원을 만들 때 교체한다.

### 🎨 표현과 커스텀 UI

- 컨셉: ‘햇살 정원’. 호기심·차이의 관찰·돌봄의 이야기를 지원하도록 설계했다.
- 배경 `#f5f7ef`, 본문 `#253e34`, 보조 글자 `#52675b`, 주요 행동·모양 윤곽 `#365d46`, 선택 경계 `#718474`, 장식 살구 `#efad85`·잎색 `#97bdaf`·보라 `#b7ade0`·노랑 `#e3c46b`.
- 대비 자동 검사: 본문 10.69:1, 보조 5.63:1, 버튼 흰 글자 7.47:1, 경계 3.70:1 이상, 모든 모양 채움/윤곽 3.58:1 이상. 화면 전체 접근성 검증은 별도다.
- 모양 선택은 실제 button 기반 큰 타일, 설정은 radio·checkbox를 카드와 스위치로 표현, dialog는 native 의미를 유지한다. 키보드 초점과 선택 표시를 색 외 윤곽·글·체크로 제공한다.
- 모바일 세로 배치, 넓은 화면의 정원 중심 구성을 사용한다. 데스크톱 시작은 두 열이다. 움직임 줄이기 설정에서는 장식 전환을 제거한다.
- 오답: ‘다른 모양이네. 테두리를 다시 살펴볼까?’ 성공: 모양 특성 안내. 종료: ‘여기까지 함께했네. 쉬어도 좋아.’
- 초기 상태·선택·정답·힌트·완료·보호자 설정은 코드와 자동 규칙 검사로 점검했고 실제 브라우저 렌더·스크린리더 검증은 미실시다.

원작의 펭귄·빈자리 퍼즐 화면·레벨 순서를 복제하지 않고, 식물 이야기·다섯 활동·명시적 다음·쉼의 자체 구성을 택했다. 파일별 반입 리소스와 원작 상표 문자열은 정적 검사한다. 원작 직접 플레이·화면별 시각 대조·상표 검색·법률 검토는 미실시이며 ‘무침해’로 보증하지 않는다. 공개 전에 [권리 검토 가이드](../../docs/guide/guide-originality-rights.md)에 따라 추가 점검한다.

### 🧱 공통 호스트 전환

현재 진입점은 shared/host와 board-activity를 사용한다. 기존 정답·저장 검사의 model.js와 storage.js는 회귀 및 호환 래퍼로 보존했다. 실행 모델은 board-model.js다. 기존 단독 스타일과 render.js는 초기 버전 참고이며 현 진입점에서는 사용하지 않는다.

초기 v1 progress의 seed·results는 완료한 활동 번호로 변환하고, 같은 키에 seed·level·actions 형식으로 저장한다. 과거에 마친 활동은 유지하지만 개별 꽃의 matched/skipped 내역은 새 화면에 표시하지 않는다. 완료한 라운드의 다음부터 이어 간다. 소리와 choices 2/3 설정은 같은 키에서 보존한다. 개별 시범 화면 대신 목표 그림·현재 조작 안내·공통 힌트를 제공한다.

### ✅ 검증과 제한

`node tools/verify-shape-garden.mjs`는 2,000개 생성 세션, 상태 전이·정답 유일성·저장 예외·대비를 검증한다. `python3 tools/verify-project.py`는 문서·정적 파일 경로·문법·외부 요청 참조를 확인한다. 런타임 외부 의존은 없으며 Playwright는 선택적인 개발자 검증 도구다.

현 실행 환경의 포트 바인딩 제한과 Chrome 실행 실패로 브라우저 플레이·레이아웃·실제 터치·Safari·VoiceOver·청취 검증은 미실시다. 자세한 결과는 [검증 기록](../../test/20261121121102-shape-garden-verify.md)을 따른다.
