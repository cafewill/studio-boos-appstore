## 📖 개요

물방울이 수증기와 구름을 거쳐 돌아오는 길을 만들어요.

## 🧩 주요 내용

- 주 대상: 만 6~8세. 조작은 화면의 이름 붙은 버튼을 선택한다. 드래그·소리는 필수가 아니다.
- 장면: 연못·수증기·구름의 순환 그림과 도구. 색: 하늘색·흰 구름·차분한 노랑.
- 도움: ‘한 걸음 도움’으로 다음 조작을 확인한다. 되돌리기·쉬기·보호자·목록은 공통 기능이다.
- 로컬 주소: `http://127.0.0.1:7902/apps/weather-studio/`.
- 파일: `src/model.js` 규칙, `src/view.js` 장면, `style.css` 배치, `cover.svg` 자체 썸네일.
- 제한: 증발·응결·강수를 단순한 단계 모형으로 표현한다. [USGS 물의 순환](https://www.usgs.gov/special-topics/water-science-school/science/water-cycle) 원문 요청은 405로 실패해 본문 확인 근거로 사용하지 않았다. 액체·기체의 실제 부피 비율이나 강수 예측은 재현하지 않는다.
